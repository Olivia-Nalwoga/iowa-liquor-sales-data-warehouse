# Retail Sales Data Warehouse in BigQuery

SEIS 732 data warehousing project using the Iowa Liquor Sales public dataset in BigQuery.

## Source

BigQuery public dataset:

`bigquery-public-data.iowa_liquor_sales.sales`

## Project goal

The goal of this project is to build a BigQuery retail sales data warehouse that supports analysis of liquor sales performance by product, vendor, store, location, and time.
